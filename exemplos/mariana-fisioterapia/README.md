# Exemplo — Mariana, fisioterapeuta

Caso de estudo fictício para testar o time do Mind Mestre de ponta a ponta.
Como a calculadora do Instalador, este material tem vestígios plantados:

| Vestígio | Onde |
|---|---|
| Medo de exposição | "medo das pessoas rirem de mim", "não gosto de aparecer" |
| Adiamento crônico | "adiando há dois anos", "todo janeiro eu prometo…" |
| Oferta nebulosa | "não sei quanto cobrar por um curso" |
| Desvalorização | "sinto culpa de cobrar até isso", "difícil subir o preço" |
| Validação da família | "minha irmã disse que ninguém vai comprar curso meu" |
| Demanda real | "clientes sempre me perguntam sobre dor no trabalho" |
| Plateia | "uns 1,2 mil seguidores" no Instagram |
| Dispersão | 5 ideias de produto abertas ao mesmo tempo |
| Objetivo declarado | "quero criar um curso sobre postura para trabalhadores de escritório" |

Rode:

    mindmestre plano exemplos/mariana-fisioterapia --sem-ia
